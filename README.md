# Практическая работа №4 — PHP. Основы языка, запросы и обработка HTML-форм

## Описание

Адаптивная панель сотрудников. Приложение читает данные из `employees.csv`, отображает таблицу сотрудников, позволяет фильтровать её через GET и добавлять запись через POST-форму. PHP проверяет данные на сервере и безопасно выводит пользовательский ввод с помощью `htmlspecialchars`.

## Требования

- PHP 8.0 или новее
- Браузер
- Терминал для запуска встроенного PHP-сервера

## Структура проекта

Все файлы находятся в корне репозитория:

```text
trpo-pro04-student/
├── index.php
├── custom.css
├── functions.php
├── employees.csv
├── form_cases.json
├── README.md
└── .gitignore
```

## Запуск

1. Открой Терминал.
2. Перейди в папку проекта.
3. Запусти встроенный PHP-сервер:

```bash
php -S localhost:8000
```

4. Открой в браузере:

http://localhost:8000

Важно: PHP-проект нельзя корректно запустить простым открытием `index.php` как файла. Для выполнения PHP-кода необходим PHP-сервер.

## Что реализовано

- Вывод версии приложения и текущей даты средствами PHP.
- Использование массивов, условий, циклов и пользовательских функций.
- Чтение CSV через `fgetcsv` с разделителем `;`.
- Функции `loadEmployees`, `normalizeEmployee`, `validateInput`, `loadFormCases` и `e`.
- POST-форма с четырьмя полями: имя, отдел, опыт работы и email.
- Серверная проверка обязательных значений, длины имени, формата email и диапазона опыта от 0 до 60 лет.
- Сохранение введённых значений в форме при ошибках и отображение сообщений валидации.
- Безопасное экранирование пользовательского ввода с помощью `htmlspecialchars`.
- GET-фильтрация сотрудников по отделу.
- Отображение тестовых сценариев из `form_cases.json`.
- Адаптивная вёрстка и горизонтальная прокрутка таблицы на небольших экранах.

## Проверка

1. Открой страницу и проверь отображение сотрудников из CSV.
2. Отправь пустую форму и проверь сообщения об ошибках.
3. Введи опыт работы `-2` и проверь валидацию диапазона.
4. Введи некорректный email и проверь сообщение об ошибке.
5. Заполни все поля корректно и проверь добавление сотрудника в таблицу текущего ответа.
6. Выбери отдел в GET-фильтре и проверь, что отображаются только сотрудники выбранного отдела.
7. Нажми «Сбросить», чтобы вернуть полный список.
8. Сравни тестовые сценарии на странице с содержимым `form_cases.json`.

## GET и POST

**GET** передаёт параметры в адресной строке и используется в проекте для фильтрации таблицы.

**POST** передаёт данные формы в теле HTTP-запроса и используется для обработки добавления сотрудника.

## Безопасный вывод

`htmlspecialchars` преобразует специальные HTML-символы в безопасные представления. Это помогает предотвратить интерпретацию пользовательского текста как HTML-разметки.

## Хранение новой записи

Новая запись добавляется в таблицу только на время текущего запроса и не записывается обратно в `employees.csv`. После обновления страницы запись исчезает. Такой вариант позволяет продемонстрировать обработку POST-формы без реализации постоянного хранения данных.
